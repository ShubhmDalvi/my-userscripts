# 🛠️ My Userscripts Collection

A centralized repository for all my custom Tampermonkey, Violentmonkey, and Greasemonkey browser userscripts.

## 🚀 How to Install

1. Install a userscript manager extension for your browser (like [Tampermonkey](https://www.tampermonkey.net/)).
2. Click the **[➔ Install]** link next to any script in the table below.
3. Confirm the installation when the extension page pops up.

## 🔄 Automatic Updates

Your userscript manager will automatically check this repository for updates periodically. When you update your code and change the `@version` tag inside your script, your browser will grab the update automatically!
